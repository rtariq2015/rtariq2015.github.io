Raspberry Pi Zero 2 W · Development software

A USB flash drive that backs up your files to Google Drive.

Connect Raspi Cloud Sync Pro to Windows with a USB data cable. CLOUDSTICK appears as a normal USB storage drive, with a drive letter assigned by Windows.

How Version 1 works

  1. Copy files onto CLOUDSTICK in Windows.
  2. Choose Eject in Windows and leave the cable connected.
  3. Capture safely. The Pi captures eligible files into local staging under verified exclusive filesystem access.
  4. Back up over Wi-Fi. The worker uploads captured files to the configured Google Drive folder using the Pi’s built-in Wi-Fi.
  5. Verify the backup. The worker downloads cloud contents for a SHA-256 check before recording the backup as verified.

Safe Eject is required in Version 1. Automatic capture while Windows continues using the drive is not implemented. Keep the USB cable connected so the Pi stays powered.

Local copies stay available

Originals and staged copies are not automatically deleted. When connectivity is unavailable, captured files remain locally queued. Retryable failures are retried; authorization and other permanent failures may require operator attention.

A working development project

The USB-to-Google Drive workflow has been tested under documented conditions. Raspi Cloud Sync Pro is not a finished production release, and verification does not guarantee protection against every hardware, storage or network failure.
